
This is my template vault! 

This repository is a template for creating an [Obsidian](https://obsidian.md/) vault. In order to utilize the template, simply download the files and put them in a folder with the desired name of your vault. Then go into Obsidian, and press `Open folder as vault`, and select the folder you just created. 

This vault contains plugins that I have made as well as community plugins, so only proceed if you wish to accept the risk of downloading and running these. 

As well as coming with preinstalled plugins and themes, this template also contains some of the settings I use, plus a few example files to give you an idea of my personal workflow with Obsidian. I also extensively explain and justify my workflow in [[My Obsidian workflow]].

For additional information on my method, consider looking at `XXX.md` in my [public vault](https://github.com/haugsjaalean-commits/public_vault), but, as a spoiler, I will say that it has a lot to do with [rhizomes](https://en.wikipedia.org/wiki/Rhizome). And, if you are just getting started with Obsidian, then I would suggest you read XXX once again in my public vault. 

If you decide to build you vault on top of mine, then I invite you to delete my files and start with a jumpstarted blank slate.

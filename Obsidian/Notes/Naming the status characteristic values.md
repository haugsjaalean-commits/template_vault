### Ideas with "idea"

- idea
- work in progress
- fulfilled

The problem with this system is that the two values from the original system, `draft` and `effort`, get mixed into one value, `work in progress`. This compression may seem elegant, but it loses us some precision. If something is a draft, that means that it will some day be implemented, but, if something is an effort, then it has no garante of eventual completion. 



### The original idea

## Thoughts

Honestly I think that my original system is the best. I thought that `idea` was a bad idea because calling a bug an idea felt really wrong to me. After thinking about this more, it's clear that a bug is not a project. A *bug fix* is a project. This means that a bug fix is just something that talks about a bug. If I only just noticed a bug, then the fix for the bug is just an idea. This makes perfect sense and I don't see any contradiction. A project is, at the heart of it, the act of turning an idea into a reality, so not using "idea" would be a bad choice.

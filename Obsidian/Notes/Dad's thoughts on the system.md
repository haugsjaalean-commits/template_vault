He thought that it was strange that the characteristic notes didn't have an `is a` attribute. This made me think pretty hard, but I told him that it didn't make sense because `is a` is only for notes. The main thing that he hadn't understood is that the so called "class" of the `.md` files is described by their folder. If one were to create a database, this would have to be put into the metadata of each file. Both the characteristic and template notes are not really even notes. They are more like code which is in the form of `.md` file.

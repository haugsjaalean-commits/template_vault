A view in the right side-bar, this plugin would allow us to have universal formulas for bases. All formulas would be a part of all bases. Adding a formula to one base adds it to all bases. 

This view can be used to add, subtract, and view the different formulas. 

There should also be an option to limit certain formulas to certain bases.

## Idea s for tab wrangler

### Tab wrapping 

when too many tabs are open, they start wrapping around. This can go up to a set number of times (configured in the settings). 

N.B. There should be an option for the current tab always takes up an entire row. 

### Tab groups 

Groups of tabs can be turned into groups. Tab groups are listed in the tab section in the sidebar. This section allows for searching and grouping tab groups. 

The tabs panel also displays the most recently used tabs and tab groups.

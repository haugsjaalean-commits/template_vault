Bases that were created from a class should have a new `Class base` option in the right next to the other options (`Filter`, `Sorting`, etc.). This option will simply give a short explanation on what a class base is, and it will also allow the option for resetting the base based on the current configuration of the class. 

N.B. This obviously means that the old reset base option can be removed from the classes panel itself.

## Advanced implementation

A more advanced implementation of this feature could allow for things like selectively changing things based on the current state of the class, instead of a complete factory reset. I think that I will think more about this once the most basic version has been implemented.

It would be cool if there was an option for constantly syncing the base based on the class. Maybe even this could be customized to only change certain things while others stay constant. This might end up relate to [[Bases Sharing]]. I really should think about where I want to go with bases, because I feel like I can get more out of them with some more customization and plugins. 

I think that the `Class base` menue should have a toggle to only see exact matches for `is a` meaning that children of the class are excluded.

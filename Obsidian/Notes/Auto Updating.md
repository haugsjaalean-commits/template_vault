It would be cool if there were options in the settings of Class Manager to allow updating to happen automatically. The user would be able to set the parameters for when this happens. For example, they could say that it should only happen when the discrepancies are only adding frontmatter and taking nothing away. They could also limit it to a certain number of discrepancies, beyond which the user will need to press the update button themselves. 

This would make the component workflow a lot smoother. When a component is added to the instance of a class, it will save the user the step of clicking the update button. This can save a lot of time in the long run. Something to think about.

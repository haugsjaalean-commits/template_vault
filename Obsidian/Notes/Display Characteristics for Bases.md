This is another addition to the OOF plugin family. 

My preposition is to add a new `display` base characteristic. Each class would list its display characteristics. Then, in a base, I could choose to display the `display` characteristic. However, instead of showing a list of characteristics, it shows the values of the characteristics. 

Implementing this is rather simple. The only thing that needs to be done is for all characteristics shown as links in a field should instead be displayed as the value held by the instance that links to them.

N.B. This may be easier to implement as an addition to Class Manager instead of a stand alone plugin, so it should be done in the easiest way.

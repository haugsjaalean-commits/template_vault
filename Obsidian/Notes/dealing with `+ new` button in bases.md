There should be an option to hide the `+ New` button. If this option is turned off, then the following logic is used for creating new notes.


## Using `+ New` to create new instances of the base's class with a template 

### How it should work

When the user presses the `+ New` button, the following things will happen:
1. A note will be created in the base with the correct template.
2. A window will pop up on screen with the option to change the automatic name assigned by Templater. 
3. Once the user clicks out of that window, they will be prompted with the places where they want to move the file. This will look exactly like as if they had grabbed the file, except instead of releasing to drop, they simply click where they want to drop. 

Both the option to be prompted for the name and the option to be prompted for the position will be toggles in the settings. 


### How it shouldn't work

The button should bring up no menu and should not prompt the user to move the file to a specific place in the basee.

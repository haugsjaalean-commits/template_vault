Each class should link to its base as a native attribute. I think that this is the best way to handle things. I thought of this because of the symbols ([[Emojis for Classes]]), which utilize the newly created native attribute `symbol` to define a symbol for each class. It would make complete sense to also think of bases in this way. They are not something added by a class; they are part of the system itself - something to aid the user in understanding and finding their notes, just like the `#class` tag which clarifies which notes are classes. I think that templates should also be put into this same category. This would  mean that the three new native attributes are: `template`, `symbol`, and `base`. They are all automatically handled by the system. I like this because it makes the system underneath more visible to the user, which was the whole point of basing my class system on the markdown links and files themselves, instead of simply using a `.js` file to store everything. 

Maybe some day I will think that it's better to come up with a different place to put these types of attributes, but for now this makes perfect sense to me.

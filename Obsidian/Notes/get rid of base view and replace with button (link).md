I want to get rid of the base view for Dynamic Sticky Notes, as it only seems to add more code without giving me any additional functionality. This means that it is not an elegant design. I think that the base view should simply be replaced with a link to the base. Simply adding a link to the base will do the same thing, but it will require many times less programming. 


## Counter argument ⚠

Above, I said that I thought that the base didn't add any additional functionality, but I was at least partly wrong. What it adds is the ability to have different dynamic queries playing out in real time as I look at different notes. I could technically add any dynamic views for the Sticky Notes base to the [[Dynamic Views]], but this would be just slightly less practical than simply using the dedicated Sticky Notes view. The way I see it, I already have a specific view for Sticky Notes, so I don't need to clutter the dynamic views with an additional dynamic Sticky Notes view. Every single note in the vault would end up having this view, since sticky notes apply to any note. This would really just be adding clutter.

This plugin would come in the form of yet another option at the top of the base. Highlighting will work sort of like a second query. Only notes which fulfil the query will be highlighted. Maye the simplest way of implementing the searching (querying) is by copying the way in which the native Obsidian graph does it for "grouping" the nodes. It basically uses a search bar with advanced search queries. 

I think that this feature should work quite similarly to the graph feature I just mentioned, as I think it would be very nice to be able to highlight with multiple different colors at once. 


## Cool thing

The cool thing about adding this feature is that it would allow me to highlight the active file in its own base. Since [[Dynamic Views]] allows me to open every files base automatically then it would be really cool to be able to see the active file highlighted in the base.

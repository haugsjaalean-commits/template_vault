If a characteristic in a note is not one that it inherits from any of its parents and it does not belong to any of the other categories of attributes or characteristics, then it should be placed under `classless characteristics`. This will be important when it comes time to merge my new method with my personal vault. 

Classless characteristics should be shown in a new panel in the main classes panel. This panel will be called the context menu. It will show different useful information about the classes and objects in the vault. Of course, one of these useful pieces of information are the notes containing classless characteristics.

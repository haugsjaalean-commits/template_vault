With 40+ classes, the wires are now taking up more space than the classes themselves. This is why I would suggest the implementation of compressed wires. This would achieved by simply overlapping parallel wires. 

If multiple wires have the same origin and are vertically parallel, then they should overlap. However, if they start in two different places, then information would be lost by making them overlap. 

---

The nice thing about this is that we don't even lose any precision, because all of the wires start off overlapping anyways. This doesn't technically change anything in that sense, but it's much more condensed.

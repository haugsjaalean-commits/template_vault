I was creating the classes necessary to keep track of my cegep stuff when I realized that it would be awesome to be able to have variables. This would be useful, because then I could set the default value for the session of a cours to be the `current_session`. I don't currently have a way to set variables like this, so it would be really cool if I could do that. 

This idea of making variables brings up a whole debate of what this system should be: Should we be able to fully program and automate our classes? How much automation do I want to be able to really have? It would be really cool if one characteristic's value changing  could start another chain of events. I think that, in order to do this, I would need to implement something closer to the system I imagined for Rhizomeur with the Automation Engine.

When a class is a `type of` multiple other classes, then we need wires to be crossing in the [[tree view for classes]]. If too many wires need to be added for crossing, we may need to add more lanes just for this, in order to avoid completely overlapping wires. When wires cross, one of the wires will go above, and the other one will go under. Ideally, the wire added for the double inheritance will be the one going under. The wire that goes under will be visibly cut off around the edges of the above wire.

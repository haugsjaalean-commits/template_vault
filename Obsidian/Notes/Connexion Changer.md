This plugin would further enhance the graph view. The basic idea is that I want links to appear differently in the graph depending on their nature, for example what metadata property they are contained in. 

The three things that I want to be able to change are:
1. **Symbol:** This will change the arrow for the chosen symbol (which still needs to have a direction)
2. **Line type:** This will change the appearance of the line to the selected appearance. (hidden is also an option, in which case the line has no forces).
3. **Line color:** Based on the property given the link can have a different color. One of these colors is the option for the line to mimic the color of the parent or the child note.
